# Crazy Cart Chat Bot Landing

Статический лендинг-квиз в формате чата для сбора заявок на франшизу Crazy Cart.

## Страницы

- `index.html` — чат-квиз с 5 вопросами и финальной формой.
- `privacy.html` — оформленная страница политики конфиденциальности.

## Публикация

Проект готов для GitHub Pages: достаточно опубликовать корень репозитория из ветки `gh-pages` или `main`.
